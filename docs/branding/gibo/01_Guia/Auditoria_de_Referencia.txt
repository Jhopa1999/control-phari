1. MATERIAL EXAMINADO

Ambos archivos tienen 1024 x 765 píxeles, modo RGB y carecen de canal alfa.
El damero gris y blanco está integrado en la imagen. Por tanto, las referencias
no son archivos transparentes utilizables directamente como maestros de marca.

2. QUÉ PUEDE MEDIRSE Y QUÉ NO

Es posible medir el tamaño del raster, sus píxeles y la posición aproximada de
los elementos. No es posible recuperar de forma concluyente a partir de estos
archivos la fuente original, el archivo vectorial maestro, la intención exacta
de cada curva ni un perfil de impresión no suministrado.

El resultado entregado se identifica como reconstrucción vectorial normalizada,
basada en las referencias. Las curvas, nodos, espacios y colores se estabilizan
para uso técnico. No se pretende conservar irregularidades del raster como si
fueran decisiones deliberadas del diseño original.

3. MÉTODO DE MUESTREO

Se seleccionaron regiones por ubicación y por intervalos RGB de marino, azul y
cian. La erosión de 5 x 5 píxeles en la referencia principal redujo la influencia
de bordes suavizados. Se calcularon mediana y moda por grupo. Estos estadísticos
describen las regiones muestreadas; no implican que toda la zona tenga una tinta
uniforme ni que esos colores fueran los valores originales de diseño.

5. PALETA FINAL ADOPTADA

Color          HEX         RGB             CMYK algebraico aproximado (%)
Navy           #0F2557     15, 37, 87      82.8 / 57.5 / 0.0 / 65.9
Electric       #176BEB     23, 107, 235    90.2 / 54.5 / 0.0 / 7.8
Cyan           #20BFD1     32, 191, 209    84.7 / 8.6 / 0.0 / 18.0

El marino retoma el código explícito del moodboard. El azul se profundiza para
permitir blanco sobre un botón de ese color con una relación de contraste 4.84:1.
El cian se aproxima al símbolo ampliado y unifica órbita y nodos.

Los HEX/RGB son los valores digitales de referencia. CMYK se calculó por la
conversión algebraica habitual basada en el máximo canal RGB. No se aplicó perfil
ICC de imprenta: los porcentajes son una orientación, no una equivalencia física
exacta. El proveedor debe efectuar la conversión para su soporte y proceso.

Colores de apoyo digital:
Blanco #FFFFFF; negro #000000; lienzo #F4F6F8; fondo oscuro #08152E;
azul funcional para enlaces/hover #145CCB.

6. CONTRASTE DE LAS COMBINACIONES PRINCIPALES

Navy / blanco:                         14.762:1
Navy / lienzo claro:                   13.626:1
Blanco / Electric:                      4.840:1
Electric / lienzo claro:                4.467:1
Azul funcional #145CCB / lienzo claro:   5.663:1
Cyan / Navy:                            6.632:1
Cyan / blanco:                          2.226:1
Blanco / fondo oscuro #08152E:          18.150:1
Cyan / fondo oscuro #08152E:             8.154:1

Método: linealización sRGB, luminancia relativa y cociente (Lclara + 0.05) /
(Loscura + 0.05). Cifras redondeadas para presentación.

El umbral de referencia para texto normal es 4.5:1. Por eso Electric sobre el
lienzo claro no se declara apto para texto normal, aunque se aproxime al umbral.
Se usa #145CCB para ese rol. Cyan sobre blanco se reserva como acento decorativo.
La marca y una interfaz completa requieren decisiones diferentes; estos cálculos
no constituyen una certificación global de accesibilidad de una aplicación.

Fuente del método y criterios:
https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

7. TIPOGRAFÍA

Montserrat e Inter aparecen nombradas en el moodboard. No puede demostrarse solo
con el raster que todas las letras del logo se generaran con una de esas fuentes.
La G y la O incorporan intervenciones gráficas propias.

Se adopta Montserrat como alternativa geométrica para titulares y descriptor,
y se recomienda Inter para interfaz, tablas y lectura. Los maestros del logo
tienen contornos: su apariencia no depende de fuentes instaladas.

Los archivos originales de ambas familias y sus licencias OFL se incluyen en
06_Fuentes. La licencia de las fuentes no demuestra exclusividad ni registro
del nombre o símbolo de marca.
